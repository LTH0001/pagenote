# 逐页精讲

读取当前文档，将每页原文讲成学习者能够逐步理解、运用的知识，并保存到对应页笔记。重点是补足理解所需的中间步骤，不是扩写字数。

## 确定任务

本技能是学习讲解的默认方法，不覆盖本次用户要求。摘要、翻译、快速查阅、代码修复等任务直接按其目标处理，不自动扩展成完整课程。用户明确要求练习或提问式教学时，按其要求调整；普通讲解保持陈述式。

- 读取当前文档、实际页数、现有笔记与 AI 标注。遵守用户指定的页码范围；只问某一页时，只处理那一页。
- 依据用户说明确定学习基础、目标与讲解语言。没有说明时，结合已有学习背景作适当假设并说明；不把某个用户的专业和年级作为所有人的默认值。
- 先看简短章节路线，识别本页依赖和后续去向。PDF 实际页码与印刷页码不同则明确区分。

按材料和页面调整内容，而不是只适配某门课：课件重视概念依赖和示例；论文区分论点、方法、实验设置和证据；技术文档强调前提、步骤与限制；人文材料说明语境、概念和论证，不强加公式或代码。封面、目录、过渡页和参考文献按其作用简明讲解，不凑篇幅；密集推导或图表页则充分展开。遇到扫描件、图表或缺失的前置知识，先读取可用截图与邻页信息；看不清的部分说明限制。

## 一页一次请求

每页作为独立的模型讲解请求。不要一次输出整章再拆页，也不要把逐页写入工具调用当成独立模型请求。

每次请求带入当前页完整原文、必要截图、学习基础、简短章节路线和上一页交接。优先为当前页的细致解释保留上下文；只压缩旧内容，不把本页推导压成摘要。

能调度独立模型请求的客户端，完成本页后再请求下一页。不能调度的客户端应说明限制，一次用户交互处理一页；不能声称已经发起多次独立请求。MCP 提供文档工具，不负责调用模型。

## 陈述式、递进式讲解

- 直接陈述知识事实，不用“为什么”“是什么”“你是否想过”等问题引入段落，不安排自问自答。
- 自然承接前页已建立的认识，再解释本页的新概念。按依赖展开：直观含义、准确概念、符号与条件、关键步骤、具体例子和结果解释。按页面内容取舍，不机械套固定小标题。
- 新符号首次出现时解释含义、单位、范围与对应对象。推导补上省略的代数或逻辑步骤，说明每一步依据，区分定义、假设和结论。
- 用一个具体例子把知识落地，尽量沿用前页的数据或场景。例子应帮助理解当前知识，不引入比原知识更复杂的前置内容。
- 区分易混淆对象和适用边界。明确原文内容、补充解释与发现的原文错误；无法看清或不能确定的地方如实标明，不补造课件结论或实验数据。
- 少用空泛总结和口号。结尾给出本页已经建立的结论，简短过渡到下一页，不以问题吊起下一页。

## 用合适的表达帮助理解

读取本机可用技能或工具，按实际内容调用，不只在笔记中建议“可以画图”。

- 图像：空间结构、工作机制、抽象类比难以用文字说明时，调用可用生图能力制作讲解图并插入本页；标明教学示意。精确坐标、数据曲线、实验结果用可靠绘图方法，不能让生图编造数值。
- Mermaid：用于流程、依赖、分类和状态转换，使用标准 mermaid 代码围栏并检查实际渲染。
- 代码：用于计算、算法或可验证的例子，注明语言和输入输出含义；普通代码块不代表已执行。有执行能力时验证关键示例，没执行则如实说明。
- 公式：行内使用 `$...$`，独立公式使用 `$$...$$`。笔记中写正常 LaTeX，不把 JSON 的双重转义保存为正文；矩阵换行保留合法的双反斜杠。公式前后解释符号、条件和结果。
- 表格：用于概念对比、步骤数据和计算结果。没有必要时保持正文简洁，不为了展示工具堆满所有形式。

缺少某项能力时，选择能表达同一知识的可用方法并说明，不伪称已经生成图片、运行代码或查看截图。

## 保存、检查与交接

1. 写入前读取本页当前 revision 和已有笔记，尊重用户编辑；使用 expectedRevision，冲突时重新读取并合并。
2. 每生成完一页，立即用笔记写入工具保存到对应页，让用户随时查看已完成内容，不等整份材料完成后集中写入。后台生成时不调用导航工具、不切换用户正在阅读的页面；仅在用户明确要求打开某页时导航。检查公式、图表、图片和代码使用后台截图，截图过长时分段查看。发现问题先修复，再进入下一页。
3. 给下一页请求传递精简交接：已讲概念、符号约定、沿用例子、本页结论、未解依赖。交接保留在客户端任务上下文，不把冗长的工作记录塞进学习者笔记。
4. 根据 AI 标注重讲时，定位引用或框选区域，读取上下文与修改要求，保留已正确内容；实际修改成功后才将标注记为完成。
5. 按实际情况报告完成页码、检查方式和未完成项。批量写入、使用长文本或工具成功返回，都不等于每页已经得到独立、充分的讲解。

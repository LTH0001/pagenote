# 逐页精讲约定

AI先读取 `page-notes://prompts/index`，识别本次任务。初始生成读取 learning、page-tutor、output；按AI Tag修改读取 tag-edit、output；确需重讲时再读 learning。提示词正文按revision复用，不一次加载全部模块。完整默认内容见 [提示词清单](PROMPTS.zh-CN.md)。

每页一次独立模型请求，不一次生成整章再拆页。建议并发数为 `max(1, floor(总页数 / 10))`，并受待处理页数、客户端子代理上限、服务配额及本机资源约束。52页建议5个，客户端最多3个则用3个；未知限制保守起步。MCP不负责调用模型，也不能保证客户端服从并发建议。

每个请求输入当前页完整材料、上一源页、下一源页及用户学习要求，首尾省略不存在的邻页。按原文知识依赖自然衔接，不等待上一页讲稿或交接。只有明确缺失定义时才向更早源页追溯。交接工具仍可用于跨会话续做，但不是并行生成前提。

讲解使用陈述式表达，解释术语、符号、条件、中间步骤和具体例子。主动使用合适的教学方式：流程图、计算或算法代码、讲解示意图、公式、比较表格；工具可用时实际制作，不只是建议。封面、目录等不硬凑形式。

每页生成时遵循Markdown与LaTeX规范；保存前调用 `page_notes_validate_note` 进行本地确定性预检，通过后用 `expectedRevision` 提交其 `normalizedMarkdown`。局部格式失败只修对应问题，不重写讲稿。不把反复人工截图审查设为固定流程，也不承诺所有设备绝对一遍过。语法预检不等于知识正确性校验。

每页完成即静默保存，可以乱序完成，不导航用户页码、不改变滚动位置。已有笔记和用户编辑必须保留，冲突时重新合并。单页失败不阻塞其他页。最终只报告实际完成范围与未验证事项。

AI设置支持分别修改系统提示词与各模块。系统提示词修改后重新连接客户端；模块版本在下次读取时更新，本机覆盖不随学习项目上传。

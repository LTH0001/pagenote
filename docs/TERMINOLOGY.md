# 术语 / Terminology

| 中文 | English | 含义 / Meaning |
| --- | --- | --- |
| 项目 | Project | 文档、页面笔记、附件和标注组成的可移动文件夹 / A portable folder containing sources, notes, assets and annotations |
| 源文档 | Source document | 左侧参考内容 / Reference content in the left pane |
| 页面笔记 | Page notes | 对应当前源页面的 Markdown / Markdown linked to the active source page |
| 选择工具 | Select | 选择文字或页面区域 / Select text or an area |
| 手形工具 | Hand | 平移阅读视图，不修改内容 / Pan the reading viewport without editing |
| 画笔 | Pen | 自由手写工具 / Freehand ink |
| 荧光笔 | Highlighter | 半透明标记 / Translucent marking |
| AI 标注 | AI annotation | 用户给 AI 的解释或修改要求，附带定位与上下文 / A user's request with location and context |
| AI 标注画布 | AI annotation canvas | 整理标注卡片的视图 / Canvas for arranging annotation cards |
| 版本历史 | Version history | 已保存笔记的历史版本 / Previously saved note versions |

“鼠标”是设备名称，不用于命名选择行为；“抓手”统一为“手形工具”。AI 标注不是自动改写结果，不使用“AI 已修改”描述尚未处理的请求。内部旧版 MCP 名称保持兼容，不视为公开产品名称。

Research sources: [Adobe text/area annotation](https://helpx.adobe.com/acrobat/desktop/share-and-review-documents/review-documents/add-markups.html), [Typora languages](https://support.typora.io/Languages-Support/), [Typora Mermaid](https://support.typora.io/Draw-Diagrams-With-Markdown/). Windows distribution follows [electron-builder NSIS](https://www.electron.build/docs/nsis/) and [Windows signing](https://www.electron.build/docs/features/code-signing/code-signing-win/).

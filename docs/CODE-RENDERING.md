# 代码显示与高亮

代码高亮在本机完成，语法规则和样式随程序打包，不依赖 CDN 或联网下载。阅读模式与笔记编辑使用同一个高亮入口。

beta.5 开发版扩大了内置语言范围，并兼容 `Java`、`Python3`、`C++`、`C#`、`MATLAB`、`R`、`ps1` 等标记。大小写统一后再渲染，`MERMAID` 也按 Mermaid 图表处理。未支持的语言保留为可阅读的纯代码；单块高亮失败不会抹去代码或阻止后续内容渲染。

本次测试覆盖断开外部网络请求后的语言高亮、实际颜色样式、Mermaid、未知语言内容保留、代码中的 HTML 安全显示，以及编辑时实时高亮。源码版本和本机 Windows x64 文件夹构建分别验证。这不等于已经复现所有其他电脑上的显示问题。

如仍异常，请提供软件版本、Windows 版本、最小代码块和截图，并区分以下表现：代码无颜色、代码空白、Mermaid 显示源码或错误、整页笔记无法显示。请去掉私人数据和密钥。普通代码块只负责显示，不会直接运行代码。
